# 汽车出口销售分析标准

本文件定义 Rongwei 插件判断客户与指导销售推进时必须遵循的标准。目标不是制造一个看起来专业的分数，而是把客户真正的采购行为、阻碍和下一步讲清楚。

## 一、分析必须先分清四类信息

1. **客户明确表达的事实**：客户原话直接确认的车型、数量、国家、采购时间、用途、身份、付款或订单节点。
2. **用户提供的事实**：广告内容、已核实车辆资料、已提供的文件或商务条件。
3. **基于证据的推断**：例如客户持续询问目的港费用，可能说明其正在评估进口可行性；必须标记为推断，并说明证据。
4. **未知或冲突信息**：客户没有说、资料没有证明，或不同轮次说法不一致。必须保留为待核实，不得补齐想象。

每一个重要结论都应有对应证据 ID、客户原话摘要或可靠来源。证据为空时，结论应降级为“未知”。

## 二、采购意向不是“问过价格”

以下行为单独出现时，不足以认定高意向：
- 只问价格或“最低价”；
- 只发送一个车型名称；
- 只询问是否有车；
- 只回复问候、点赞或“OK”；
- 只要求发送目录或更多照片。

更有价值的采购证据包括：
- 明确具体车型、年款、配置和用途；
- 给出采购数量、目的国家或港口；
- 说明采购时间和业务身份；
- 询问出口文件、认证、运输、付款或进口流程；
- 对一个具体方案作出回应；
- 同意通话、提供公司资料、索取形式发票或合同；
- 按约定推进下一步。

这些信号仍需看上下文。一个进口商问运输，不代表一定会买；一个终端客户暂时没有公司资料，也不能因此自动判定无效。

## 三、评分规则

evidence_score 是可解释的采购行为证据指数，不是成交概率、转化率预测或 AI 的主观感觉。

- 同一个信号只计一次，重复提及不能无限累加。
- 价格询问本身不加高意向分。
- 缺失信息不自动扣分。
- 负向信号要单独列出，不能抹掉已有的积极证据。
- “接近订单”必须有形式发票、合同或明确订单节点等直接证据。
- confidence（判断可信度）与 evidence_coverage（关键信息覆盖率）分开呈现。
- 分数不得被解释为“70 分就是 70% 会成交”。

## 四、销售阶段

| 阶段 | 判定依据 | 销售重点 |
|---|---|---|
| 新询盘 | 尚无可追溯采购信息 | 确认需求，不要直接推销 |
| 需求确认 | 已有零散信息，关键字段不足 | 车型、数量、国家、时间、买家身份 |
| 合格机会 | 核心采购条件已有多项明确证据 | 确认决策链和采购可行性 |
| 方案匹配 | 客户已认可某个车型/配置方案 | 核对具体规格与差异 |
| 商务流程 | 已讨论商务条件或运输流程 | 清除最重要的商务障碍 |
| 订单流程 | 明确索取形式发票或合同 | 核对买卖双方、订单要素与文件 |
| 订单确认 | 订单得到明确确认 | 核对合同、订单主体和正式履约条件 |
| 待付款 | 有启动付款的明确记录 | 核对付款安排与到账凭证 |
| 已核实到账 | 卖方已核对到账或有可靠外部凭证，且证据标记为已验证 | 核对付款方、对应订单和后续履约准备 |

阶段只能按实际证据推进，不允许因为分数高就跳过阶段。付款到账必须由卖方核实或可靠外部凭证支持，并将对应证据标记为 `is_verified=true`；客户自述“已付款”不能标记为到账。若客户拒绝/取消记录与订单或付款节点同时存在，必须按时间顺序核实；缺少时间戳时标记状态冲突，不要猜测当前阶段。

## 五、一次分析应回答的核心问题

1. 客户究竟想买什么车，用于什么业务？
2. 哪些信息已经确定，分别由什么证据支持？
3. 哪些信息还缺失，最影响下一步的是哪一项？
4. 客户有哪些真实购买信号？哪些只是普通咨询？
5. 客户当前最大的顾虑或成交障碍是什么？
6. 客户处于什么阶段？为什么？
7. 这一次沟通最应该达成的一个目标是什么？
8. 应该问客户什么，或提供什么资料，才能推动下一步？
9. 应该用客户的哪种语言回复？如何自然表达？
10. 哪些内容在核实前绝对不能承诺？

## 六、回复生成标准

- 使用客户实际使用的语言，不生硬逐字翻译。
- 自然、简短、专业、有推动力，不使用客服套话。
- 一次只推动一个清晰的下一步。
- 优先回应客户当前顾虑，再推动采购动作。
- 未经用户授权，不提供或编造价格。
- 不编造车辆参数、库存、装运时间、海运费、交付周期、付款条件、认证或订单状态。
- 不能确认时直接说明需要核实。
- 只生成可供用户审核的回复草稿，不自动发送。

## 七、未成交复盘

未成交原因必须基于记录，允许多选，但要区分：
- 产品或车型不匹配；
- 预算或商务条件不匹配（不能自行推测具体预算）；
- 进口法规、认证或文件问题；
- 运输或目的港问题；
- 信任、资质或付款安全问题；
- 采购计划未成熟；
- 决策人缺席或审批受阻；
- 竞争对手因素（必须有客户反馈证据）；
- 销售跟进不到位；
- 信息不足，无法判断。

复盘输出应包含：证据、根因、可控/不可控因素、销售本可采取的动作、下一次具体改进。不得把所有未成交简单归因于“客户没预算”。
